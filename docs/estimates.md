# 估算是怎么算的

下轮费用估算回答的是「下一步怎么走更省」：继续当前会话、等到下一个峰谷切换、现在执行 `/compact`，还是新开一个会话。这些数字是公开标准价估算，**不是官方账单**；插件不会自动换模型，也不会替你执行 `/compact`，更不会把会话正文送出本机。

更短的功能说明见 [README](../README.md#下轮费用估算)；英文版见 [How estimates are computed](./estimates.en.md)。

## 取样与 token 构成

估算只使用本会话**最近 8 次已计费请求**（不足 8 次则全用）。对四个用量桶分别取中位数，再送给与用量统计相同的计价引擎，而不是另建一套价格路径：

- 未缓存输入
- 缓存读取（命中）
- 缓存写入
- 输出

四个桶的中位数是独立计算的，因此合成的「典型一轮」可能与任何单次历史请求都不完全相同。下轮实际用量也可能不同，例如上下文压缩、大段粘贴或视觉输入。

没有已计费请求时，卡片会说明无法估算，而不会把费用显示为 $0。

## 四种下一步

| 选项 | 怎么计价 |
| --- | --- |
| 当前时段继续 | 用上面的中位数用量，按**现在**的峰谷（或标准价）计价。 |
| 等待下个峰谷切换 | 用量不变，把计价时间推到下一次高峰↔低谷切换。仅 DeepSeek 官方价有峰谷；StepFun / Tokener 不套用该倍率，因此不会出现这一行。 |
| 现在 `/compact` | **摘要请求**费用 + **压缩后首轮**费用。摘要请求读取整段历史（已缓存部分仍按命中计），输出按约 4,000 tokens 估算，且不超过历史长度的四分之一。压缩后的首轮里，仅会话中曾经出现过的**最小缓存命中前缀**仍命中，摘要文本与新的输入均按未命中计；输出仍用中位数。实际摘要长度和压缩所用模型可能不同。 |
| 新开会话 | 把当前的缓存读取全部改算为未命中，输出与缓存写入不变，模拟「没有前缀可命中」的新会话。 |

「继续本会话相对新开可节省」来自「新开会话」与「当前时段」的差额。插件还可以对照本 Harness 已配置、且能按官方目录定价的其他模型（同一中位数用量、当前时段）；无法定价的模型会被省略，不会显示为 $0。Tokener 模型只作为当前会话对照，不会被当作官方备选目录展开。

## 价格、峰谷与局限

- **DeepSeek**：按[官方美元定价](https://api-docs.deepseek.com/quick_start/pricing/)和北京时间峰谷。高峰为周一至周五 09:00–12:00、14:00–18:00（不含中国法定节假日）；周末和法定节假日全天低谷。内置节假日日历目前到 2027 年，超出后会按普通工作日估算并给出提示。
- **StepFun**：按官方人民币标准价。`step-5-preview` 缓存命中标准价自 2026-10-14 起为 0.70 元／百万 tokens；此前已按量调用的账户可能仍适用 0.35 元，插件无法识别该保留价，一律按标准生效时间计价，并在卡片上注明。
- **Tokener**：按 2026-11-03 目录快照的美元参考价，不套用原厂价格或 DeepSeek 峰谷倍率。含未公开价格的缓存写入时，该次估算会被省略。
- 插件配置里的 `pricingOverrides` 与用量统计共用；配置了 `usdToCny`（或在统计页填写了显示汇率）时，才会出现人民币合计，并标明是固定汇率换算。

套餐、折扣、账户特殊价格或不在目录里的历史调价，都可能导致实际扣款与估算不同。

## 在哪里查看

- 当前会话的「消费」页，以及用量统计里点击会话名后的下钻页，都会显示完整估算卡片。
- 聊天框下方的余额条可按需展开同一估算，默认收起。
- 本机只读接口：`GET /dsh-balance/api/advice?session=…`（也可用 `sessionId`；可选 `provider`、`model` 与重复的 `compare=provider:model`）。仅本机可访问，响应不含 prompt 或会话正文。

本版本**没有**可供模型调用的 agent tool。只读的 `dsh_balance_advise` 仍在[路线图](../ROADMAP.md)中；在此之前，请使用上面的界面或本机 HTTP 接口。

本地预览（无需密钥）：

```bash
pnpm preview
```

然后打开 `?page=session` 查看会话消费页与估算卡片，或 `?page=usage` 查看统计总览并下钻到某个会话。可加 `&lang=en`、`&lang=zh-tw`、`&theme=dark`。
